MagicPlay for Android

User Guide

Prepare a setlist, play WAV backing tracks, configure MIDI and control Art-Net / DMX lighting during a live performance.

Before you start: MagicPlay is designed for Android 8.0 or later. Prepare and test your setlist before using the app on stage. Menu wording may vary slightly between beta versions.

Beta software: MagicPlay is provided “as is”, to the extent permitted by applicable law. Bugs may occur, and there is no guarantee that issues will be fixed or support provided. Keep backups of your audio files and setlist data, and test your complete setup before a live performance. See the Support page for details.

1. Prepare your setlist

  1. Open MagicPlay on your Android device.
  2. Use the track management screen to import the WAV files you want to use.
  3. Check that each track appears in the list and that the order matches your set.
  4. Reorder tracks when needed using the list's reorder control.

MagicPlay stores imported audio and track settings in the app. Keep a separate copy of your original audio files.

2. Test audio playback

  1. Select a track and start playback.
  2. Listen to the output and confirm that the correct audio is playing.
  3. Adjust the track's volume to match the rest of your set.
  4. Stop playback and start the track again to confirm that everything behaves as expected.

Track volume settings are saved, so your levels are retained when you leave the screen or restart the app.

3. Use Concert Mode

Concert Mode is the performance screen. It gives you quick access to the active track, playback controls, its volume and the MIDI connection status.

  • Check the current track before starting playback.
  • Use the playback controls to start or stop the track.
  • Adjust the active track's level as needed during the show.
  • Check the MIDI status indicators before relying on MIDI actions.

Keep MagicPlay in the foreground during a performance. Avoid leaving the app or force-stopping it while playing.

4. Set up MIDI

  1. Connect a compatible MIDI device using USB or Bluetooth, as supported by your Android device and MIDI interface.
  2. Open the MIDI configuration screen and select or configure the device.
  3. Define the MIDI messages you need, such as Program Change (PC) or Control Change (CC), including the relevant channel and values.
  4. Save the settings and check that the device is shown as connected.

Connection availability depends on the MIDI interface, Android device, Bluetooth pairing and required Android permissions. Test the complete connection before the show.

5. Attach MIDI actions to a track

  1. Open the settings for the relevant track.
  2. Enable MIDI for that track if the option is available.
  3. Add or select the MIDI messages that should be sent for the track.
  4. Save the changes, then play the track and verify that the connected equipment responds as expected.

MagicPlay can send configured MIDI actions during track playback. Always test the messages with your equipment before a live performance.

6. Configure Art-Net / DMX lighting

  1. Open Art-Net Configuration and enter the IP address of your Art-Net node and the DMX universe to use.
  2. Open Fixture Types to define each fixture model and its DMX channels, including the function assigned to each channel.
  3. Open Installed Fixtures to add the fixtures in your rig and assign their DMX start addresses.
  4. Use the Scene Library to create named lighting scenes with the required channel values.
  5. Assign a lighting scene to the relevant track event, then test it with the node and fixtures connected.

Check the node IP address, universe, fixture start addresses and channel ranges carefully. Test lighting changes before relying on them during a live performance.

7. Export and restore configuration

Open Import / Export Setlist to export a JSON backup or import a previously exported backup. The backup includes track settings and events, MIDI configuration and Art-Net configuration. It does not include WAV audio files.

Keep the WAV files separately. After restoring a backup on another installation, make sure the corresponding audio files are present on the device and verify the setlist and connected equipment.

8. Before going on stage

  • Import and test every WAV track.
  • Check the setlist order and individual track levels.
  • Connect MIDI equipment and verify the connection status.
  • Test MIDI actions with the instrument or processor they control.
  • Check the Art-Net node, universe, fixtures and lighting scenes.
  • Keep your Android device charged and use reliable audio and network connections.

Need help?

If something does not work, note your Android device model, Android version, the MIDI interface you are using and the steps that reproduce the problem. Visit the Support page or report the issue through GitHub Issues.
