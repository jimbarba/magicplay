Privacy Policy

How MagicPlay handles information while you organise and run your live-performance setup.

Last updated: October 24, 2026

This page summarises the intended data handling described for MagicPlay. It should be reviewed whenever the app's permissions, integrations, or data practices change.

Overview

MagicPlay is designed to work without requiring a user account. The app is not intended to collect personal information for advertising, analytics, or user profiling.

Information used by the app

Audio files, setlists, track settings, and MIDI configurations are used to provide the app's features. These items are managed on the user's device. If configuration export or sharing is added, the user should review the exported content before sharing it.

Device and network connections

MagicPlay may connect to MIDI equipment over supported device connections. Art-Net / DMX network control is planned for a future update. When implemented, it will send control data to the lighting equipment configured by the user.

Advertising and analytics

MagicPlay is not designed to include third-party advertising or analytics services. This statement should be updated if that changes in a future release.

Children's privacy

MagicPlay is a live-performance tool and is not designed to collect personal information from children.

Changes to this policy

This policy may be updated when the app's features or data practices change. The date at the top indicates the latest revision of this page.

Contact

For privacy questions, contact the project through the MagicPlay GitHub issue tracker.
