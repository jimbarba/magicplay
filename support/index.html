Support

Find practical guidance for setting up MagicPlay and troubleshooting your live-performance workflow.

Need help with a specific issue?

Open an issue on the project's GitHub page. Include the MagicPlay version, your Android device and Android version, the steps that led to the problem, and any error message you saw. Do not include passwords or private information.

Getting started

  • Create a setlist and add your WAV audio tracks.
  • Adjust each track's level before the performance.
  • Open the MIDI configuration to connect compatible equipment and define MIDI actions.
  • Use Concert Mode for playback during your set.

MIDI setup

MagicPlay supports MIDI Program Change and Control Change actions. Check that your MIDI device is powered on, available to Android, and selected in MagicPlay. If a device does not connect, note whether it uses USB or Bluetooth MIDI and describe what the app displays.

Audio playback

Use supported WAV files and confirm that the device's audio output is connected as expected. If playback behaves unexpectedly, report the file format, the track involved, and the steps needed to reproduce the issue.

Art-Net / DMX lighting

MagicPlay supports configuring an Art-Net node, fixture types, installed fixtures and named lighting scenes. Scenes can be associated with track events. Before a show, verify the node address, DMX universe, fixture addresses and scene values.

Configuration backup

Use Import / Export Setlist to save or restore track settings and events, MIDI configuration and Art-Net configuration. WAV audio files are not included and must be kept separately. Always test a restored configuration before a live performance.
